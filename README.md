# 家計簿

スマホのブラウザで使う家計簿アプリです。HTMLファイル1つで動き、サーバーは要りません。

## できること

- **記録**：金額 → カテゴリ（アイコン付き）→ 保存。日付は今日が最初から入っています。続けて何件でも入力できます
- **ホーム**：今月の収入・支出・収支、予算の残り、カテゴリ別の支出（多い順の棒グラフ）、直近6か月の推移
- **履歴**：日付ごとの一覧。タップで編集・削除。カテゴリやメモで絞り込み
- **予算**：カテゴリごとに毎月の予算を決めると、使った額と残りを表示。超えると赤＋「⚠ 超過」
- **固定費**：家賃・サブスクなどを登録すると、毎月その日になったら自動で記録
- **CSV**：今月分／全期間の書き出し、読み込み（Excel・Googleスプレッドシートで開ける）
- **バックアップ**：予算・固定費・カテゴリも含めた全データをJSONで保存・復元
- ダークモード、オフライン、ホーム画面への追加に対応

## データの保存場所（大事）

記録は **使っている端末のブラウザの中だけ** に保存されます。どこにも送信されません。
そのため、次の場合は記録が消えます。

- ブラウザの履歴・サイトデータを消したとき
- 機種変更したとき、別のブラウザで開いたとき

月に1回くらい「設定 → 全データをバックアップ（JSON）」で保存しておいてください。
新しい端末では「バックアップから復元（JSON）」で元に戻せます。

## 使い始め方（GitHub Pages で公開する）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch でこのアプリが入っているブランチと `/ (root)` を選んで **Save**
4. 数分後に表示される URL（`https://<ユーザー名>.github.io/kakeibo/`）をスマホで開く
5. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

※ 無料プランで GitHub Pages を使うには、リポジトリを Public にする必要があります。
公開されるのはアプリのプログラムだけで、家計のデータ（端末の中）は公開されません。

## CSV の形式

```
日付,種別,カテゴリ,金額,メモ
2026-11-10,支出,食費,3200,スーパー
2026-11-25,収入,給与,250000,
```

- 1行目の見出しで列を見分けます。必須は「日付」「金額」。種別がなければ支出として読み込みます
- 日付は `2026-11-10` / `2026/11/10` / `2026年11月10日` のどれでも読めます
- 文字コードは UTF-8（Excel の古い形式の Shift_JIS も読めます）
- 読み込み時に「追加（まったく同じ内容の行は除く）」か「置き換え」を選べます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・処理すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで開けるようにするキャッシュ |
| `icons/` | アプリのアイコン |

`index.html` を更新したら、`sw.js` の `CACHE` の番号（`kakeibo-v1` → `kakeibo-v2`）を上げてください。
