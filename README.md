# 家計簿

スマホのブラウザで使う、月ごとの家計の計画アプリです。HTMLファイル1つで動き、サーバーは要りません。
スプレッドシートで「収入 − 固定費 − 積立 − 変動費」と「口座の移動」を毎月計画していた方法を、そのままアプリにしています。

## 画面

| タブ | できること |
|---|---|
| **今月** | 残り（収入 − 固定費 − 積立 − 変動費）を大きく表示。帯グラフで収入の内訳がひと目でわかる。①（収入 − 固定費）・②（① − 積立）・残りの順に計算。収入／固定費／積立／変動費の項目ごとに ✓（済み）を付けられる |
| **口座** | 口座ごとに「移動前の残高」を入れると、必要額と移動する額（入金／出金）、移動後の残高が自動で出る |
| **＋** | 使ったお金を記録すると、変動費（食費など）の残りが出る |
| **推移** | 月ごとの固定費・積立・変動費と収入のグラフと表 |
| **設定** | 名義・口座・支払い方法の登録、バックアップ、CSV |

### 自動で計算するもの

- **必要額**：その口座から引き落とされる項目（支払い方法に「引落先の口座」を設定したもの）の合計を、千円単位で切り上げた額
- **移動する額**：移動後に必要額を下回らないよう、千円単位で計算（足りなければ入金、余れば出金）
- **手持ちで用意する額**：支払い方法が「現金（手持ち）」の項目の合計

必要額と移動する額は手で変えられます（「自動に戻す」で元に戻ります）。

### 新しい月

まだ計画がない月を開くと「前の月をコピーして作る」ボタンが出ます。
収入・固定費・積立・変動費の項目と金額がコピーされ（チェックは外れた状態）、口座の「移動前の残高」には前の月の移動後の残高が入ります。

## データの保存場所（大事）

記録は **使っている端末のブラウザの中だけ** に保存されます。どこにも送信されません。
そのため、ブラウザのデータを消したとき・機種変更したとき・別のブラウザで開いたときは消えます。
月に1回くらい「設定 → 全データをバックアップ（JSON）」で保存してください。新しい端末では「バックアップから復元」で戻せます。

## 使い始め方（GitHub Pages で公開する）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch** にし、このアプリのブランチと `/ (root)` を選んで **Save**
3. 数分後に表示される URL をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

※ 無料プランで GitHub Pages を使うには、リポジトリを Public にする必要があります。
公開されるのはアプリのプログラムだけで、家計のデータ（端末の中）は公開されません。
**家計のデータ（バックアップのJSONやCSV）はこのリポジトリに入れないでください。**

## CSV の形式

計画（設定 →「計画をCSVで書き出す」で出る形式。読み込みも同じ形式）

```
月,区分,項目,名義,口座・支払い方法,金額,済,メモ
2026-11,収入,給与,夫,給与口座,250000,済,
2026-11,固定費,電気代,,引落(銀行A),12000,,
2026-11,変動費,食費,,手持ち,30000,,
```

- 区分は「収入」「固定費」「積立」「変動費」のどれか
- 口座・支払い方法が未登録の名前なら、読み込み時に自動で登録します（引落先の口座はあとで設定）

使ったお金の記録

```
日付,項目,金額,メモ
2026-11-10,食費,3200,スーパー
```

文字コードは UTF-8（Excel の古い形式の Shift_JIS も読めます）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・処理すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで開けるようにするキャッシュ |
| `icons/` | アプリのアイコン |

`index.html` を更新したら、`sw.js` の `CACHE` の番号を上げてください（今は `kakeibo-v2`）。
