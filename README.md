# 家計簿

スマホのブラウザで使う、月ごとの家計の計画アプリです。HTMLファイル1つで動き、サーバーは要りません。
「入ってくるお金を、どの口座に いくら 分けるか」を毎月決めるためのアプリです。

## 使い方

画面と操作は iPhone の標準アプリ（設定・リマインダー・カレンダー）を参考にしています。
見た目は、色のついた背景の上にすりガラスのパネルを重ねるデザイン（グラスモーフィズム）です。

1. いちばん上に「のこり」が大きく出ます。その下に、口座ごとに いくら入れるか が並びます
2. 給料を口座に分けたら、左の丸をタップして完了にします（行を左にスワイプしても完了にできます）
3. 口座をタップすると中身が出ます。項目をタップ → 金額を入れて［完了］
4. 項目を消すときは、行を左にスワイプして［削除］（すぐ下に出る［取り消す］で元に戻せます）
5. 月は右上の ‹ › か、画面を左右にスワイプして変えます。［今月］で今月に戻ります
6. 下から出る画面は、上のつまみを下に引っ張るか［閉じる］で閉じます

- 口座に分ける額 ＝ その口座から払うものの合計を 1,000円単位で繰り上げた額（「設定」で 1万円・100円・繰り上げなし に変えられます）
- 手持ちは「現金でおろす」額、給料が入る口座から払うものは「残しておく」額として出ます
- 口座に先月の余りがあるときは、［💰 先月の余りを入れる］で口座ごとに入れると、その分だけ入れる額が減ります（入れる額 ＝ 払うものの合計 − 余り を繰り上げ）。口座をタップした画面でも入れられます
- 払うものは **分類** で来月の扱いが決まります（追加・変更の画面、金額の画面で選ぶ）
  - **固定費**：毎月同じ額。来月も同じ金額で入ります
  - **変動費**：毎月額が変わる。来月は項目だけ入り、金額は空になります。「金額を入れる」の印が付き、金額の画面の「先月と同じ」でも入れられます
  - **積立**：毎月同じ額を貯める。来月も同じ金額で入ります
  - **今月だけ** をオンにすると、分類に関係なく来月には入りません
  - 新しく追加するときは、名前から分類を自動で選びます（例：電気代・カード → 変動費、積立・貯金 → 積立。選び直せます）
  - 「今月」の「分類ごと」で、分類ごとの合計と中身を見られます
- **貯金から出す**：積立の項目で「貯金から出す」をオンにすると、その口座からお金を出して生活費に回します（金額はマイナスで数え、積立の合計から引きます。スプレッドシートの「貯金 −135,000」と同じ）
  - 「のこり」が足りないときは［貯金から出して補う］を押すと、足りない額（1,000円単位で切り上げ）で作れます。用途か名前に「貯金」がある口座を選んでおきます
  - 「今月だけ」が最初からオンなので、来月にはコピーされません
- 入ってくるお金は、項目ごとに「来月は」を **同じ額／額が変わる／今月だけ** から選びます
- 新しい月になると、上のルールで前の月から自動で作ります（✓ は外れた状態）。金額を入れていないものは「のこり」の下と口座の行に件数が出ます
- 「今月」のいちばん下のボタンで、表示中の月を先月の内容で入れ直せます（ルールは同じ。今の内容は置き換わり、✓ は外れます）
- 口座には **名義**（夫・妻など）と **用途**（給与の受け取り・引き落とし など）を入れられます（「設定」の口座から）。用途を入れると、「今月」の口座の行に払うものの代わりに出ます
- **カード払い**：「設定 → カードを追加」でクレジットカードと引き落とし口座を登録すると、払うものの「払う口座・カード」でカードを選べます
  - カードで払うものの合計は、引き落とし口座に入れる額に足されます（「今月」にカードの行は出ません）
  - 口座をタップすると、「払うもの」と「○○カードで払う」に分かれて出ます。カードの欄から、そのカードで払うものを追加できます
  - カードを追加したとき、同じ名前の払うもの（例：「楽天カード」の請求額）があれば、カード払いに移すか聞きます
- 口座ごとに **色** を選べます（「設定」の口座から。選ばなければ銀行は青、現金は緑）
- 口座の **順番** は「設定 → 口座の［並べ替え］」で、右の ≡ を上下に引っ張って入れ替えます。「今月」もこの順に並びます

### 一覧のページ

下のタブの［一覧］で、その月の内容を **収入・積立・固定費・変動費** に分けて見られます（ほかの画面と同じ角丸のリスト）。

- 区分ごとに件数と合計、項目ごとに口座と金額を出します
- いちばん下の「まとめ」で、収入 − 支出 ＋ 先月の余り − 口座ごとの繰り上げ ＝ のこり を出します（「今月」の画面ののこりと同じ数）
- 項目をタップすると金額を変えられます。区分ごとの［○○を追加］で、その区分に項目を足せます
- 月は右上の ‹ › で変えます

## データの保存場所（大事）

記録は **使っている端末のブラウザの中だけ** に保存されます。どこにも送信されません。
そのため、ブラウザのデータを消したとき・機種変更したとき・別のブラウザで開いたときは消えます。
月に1回くらい「設定 → バックアップを保存」で保存してください。新しい端末では「バックアップから戻す」で戻せます。

### Googleドライブに保存する

iPhone では「バックアップを保存」を押すと共有の画面が出ます。

- Googleドライブのアプリが入っていれば、［ドライブ］を選ぶとドライブに保存されます
- または［"ファイル"に保存］→ 保存先に Googleドライブ を選びます（「ファイル」アプリで Googleドライブ を有効にしておく）
- 戻すときは「バックアップから戻す」で、Googleドライブ にあるファイルを選びます

※ 自動で保存し続ける機能（同期）はまだありません。手で保存してください。

### リンクでデータを入れる

`https://（このアプリのURL）/#import=KAKEIBO1:…` の形のリンクを Safari で開くと、そのデータが入ります（データがすでにあるときは確認が出ます）。
「#」より後ろはサーバーに送られないので、データはスマホの中だけで読まれます。入れたあとは、URL から自動で消します。
ホーム画面に追加したアプリは Safari とデータの保存場所が別なので、そちらには下の「コード」で入れてください。

### コードでデータを移す

ファイルを使わずにデータを移せます（ホーム画面のアプリと Safari のあいだ、別のスマホなど）。

- 渡す側：「設定 → データをコードでコピー」で、`KAKEIBO1:` で始まるコードがコピーされます
- 受け取る側：「設定 → コードを貼り付けて戻す」に貼り付けて［戻す］

iPhone では、ホーム画面に追加したアプリと Safari でデータの保存場所が別です。アイコンを入れ直すと、データは空になります。

## 使い始め方（GitHub Pages で公開する）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch** にし、このアプリのブランチと `/ (root)` を選んで **Save**
3. 数分後に表示される URL をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

※ 無料プランで GitHub Pages を使うには、リポジトリを Public にする必要があります。
公開されるのはアプリのプログラムだけで、家計のデータ（端末の中）は公開されません。
**家計のデータ（バックアップのJSONやCSV）はこのリポジトリに入れないでください。**

## CSV の形式

「設定 → 表計算用に書き出す」で出る形式です。読み込みも同じ形式です。

```
月,種類,なまえ,口座,金額,メモ,分類
2026-11,入ってくる,給与,A銀行,250000,,
2026-11,払う,電気代,B銀行,8000,,固定費
2026-11,払う,食費,手持ち,30000,,変動費
```

- 種類は「入ってくる」か「払う」
- 分類は「固定費」「変動費」「積立」（省略すると名前から推測します）
- 口座が未登録の名前なら、読み込み時に登録します
- 文字コードは UTF-8（Excel の古い形式の Shift_JIS も読めます）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・処理すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで開けるようにするキャッシュ |
| `icons/` | アプリのアイコン（Google の Material Symbols「account_balance_wallet」から作成） |

`index.html` を更新したら、`sw.js` の `CACHE` の番号を上げてください（今は `kakeibo-v27`）。

## アイコンについて

画面とアプリのアイコンは、Google の [Material Symbols](https://fonts.google.com/icons)（Rounded、Apache License 2.0）を使っています。
オフラインでも表示できるよう、アイコンの形のデータを `index.html` の中に入れています。

## フォントについて

- 文字：Google Fonts の Noto Sans JP（本文は Regular 400、見出しと金額は SemiBold 600）
- 数字と記号（0〜9 , . ¥ − + %）：Google Fonts の Barlow（Regular 400・Medium 500・SemiBold 600）
  - DIN 2014 は ParaType の有料フォントで Google Fonts にないため、DIN に近い Barlow を使っています
  - Google Fonts の `text=` 指定で数字と記号だけを読み込み、ほかの文字は Noto Sans JP で表示します
- フォントは一度読み込むと `sw.js` が保存するので、オフラインでも同じ見た目で表示されます
