# 家計簿

スマホのブラウザで使う、月ごとの家計の計画アプリです。HTMLファイル1つで動き、サーバーは要りません。
「入ってくるお金を、どの口座に いくら 分けるか」を毎月決めるためのアプリです。

## 使い方

画面と操作は iPhone の標準アプリ（設定・リマインダー・カレンダー）を参考にしています。
見た目は、色のついた背景の上にすりガラスのパネルを重ねるデザイン（グラスモーフィズム）です。

1. いちばん上に「のこり」が大きく出ます。その下に、口座ごとに いくら入れるか が並びます
2. 給料を口座に分けたら、左の丸をタップして完了にします（行を左にスワイプしても完了にできます）
3. 口座をタップすると中身が出ます。項目をタップ → 金額を入れて［完了］
4. 項目を消すときは、行を左にスワイプして［削除］（すぐ下に出る［取り消す］で元に戻せます）
5. 月は右上の ‹ › か、画面を左右にスワイプして変えます。［今月］で今月に戻ります
6. 下から出る画面は、上のつまみを下に引っ張るか［閉じる］で閉じます

- 口座に分ける額 ＝ その口座から払うものの合計を 1,000円単位で繰り上げた額（「設定」で 1万円・100円・繰り上げなし に変えられます）
- 手持ちは「現金でおろす」額、給料が入る口座から払うものは「残しておく」額として出ます
- 口座に先月の余りがあるときは、［💰 先月の余りを入れる］で口座ごとに入れると、その分だけ入れる額が減ります（入れる額 ＝ 払うものの合計 − 余り を繰り上げ）。口座をタップした画面でも入れられます
- 項目は「毎月入れる」か「今月だけ」かを選べます（追加・変更の画面のチェック）。新しい月になると、「毎月入れる」ものだけを前の月の金額で自動で作ります（✓ は外れた状態）
- 「今月」のいちばん下のボタンで、表示中の月を先月の「毎月入れる」ものに入れ直せます（今の内容は置き換わり、✓ は外れます）

## データの保存場所（大事）

記録は **使っている端末のブラウザの中だけ** に保存されます。どこにも送信されません。
そのため、ブラウザのデータを消したとき・機種変更したとき・別のブラウザで開いたときは消えます。
月に1回くらい「設定 → 全データをバックアップ（JSON）」で保存してください。新しい端末では「バックアップから復元」で戻せます。

## 使い始め方（GitHub Pages で公開する）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch** にし、このアプリのブランチと `/ (root)` を選んで **Save**
3. 数分後に表示される URL をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

※ 無料プランで GitHub Pages を使うには、リポジトリを Public にする必要があります。
公開されるのはアプリのプログラムだけで、家計のデータ（端末の中）は公開されません。
**家計のデータ（バックアップのJSONやCSV）はこのリポジトリに入れないでください。**

## CSV の形式

「設定 → 表計算用に書き出す」で出る形式です。読み込みも同じ形式です。

```
月,種類,なまえ,口座,金額,メモ
2026-11,入ってくる,夫給与,夫SMBC1,239862,
2026-11,払う,楽天カード,夫ゆうちょ,147232,
2026-11,払う,食費,手持ち,30000,
```

- 種類は「入ってくる」か「払う」
- 口座が未登録の名前なら、読み込み時に登録します
- 文字コードは UTF-8（Excel の古い形式の Shift_JIS も読めます）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・処理すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで開けるようにするキャッシュ |
| `icons/` | アプリのアイコン（Google の Material Symbols「account_balance_wallet」から作成） |

`index.html` を更新したら、`sw.js` の `CACHE` の番号を上げてください（今は `kakeibo-v4`）。

## アイコンについて

画面とアプリのアイコンは、Google の [Material Symbols](https://fonts.google.com/icons)（Rounded、Apache License 2.0）を使っています。
オフラインでも表示できるよう、アイコンの形のデータを `index.html` の中に入れています。

## フォントについて

- 文字：Google Fonts の Noto Sans JP（Medium 500・Bold 700）
- 数字と記号（0〜9 , . ¥ − + %）：Google Fonts の Barlow（Medium 500・Bold 700）
  - DIN 2014 は ParaType の有料フォントで Google Fonts にないため、DIN に近い Barlow を使っています
  - Google Fonts の `text=` 指定で数字と記号だけを読み込み、ほかの文字は Noto Sans JP で表示します
- フォントは一度読み込むと `sw.js` が保存するので、オフラインでも同じ見た目で表示されます
