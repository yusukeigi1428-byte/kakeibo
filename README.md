# 家計簿

スマホのブラウザで使う、月ごとの家計の計画アプリです。HTMLファイル1つで動き、サーバーは要りません。
「入ってくるお金を、どの口座に いくら 分けるか」を毎月決めるためのアプリです。

## しくみ

項目（収入・固定費・変動費・積立）はすべて **口座** につなぎます。口座は3種類です。

| 種類 | 例 | 意味 |
|---|---|---|
| 🏦 銀行口座 | 夫SMBC1、妻UFJ、夫ゆうちょ | 収入が入る・引き落とされる・貯める |
| 💴 現金（手持ち） | 手持ち | 現金で払う・封筒で取っておく |
| 💳 カード | 楽天カード | カードで払う。請求は「引き落とし口座」から落ちる |

## 画面

| タブ | できること |
|---|---|
| **今月** | 「入ってくる − 口座に分ける ＝ のこり」を大きく表示。その下に ① 入ってくるお金、② 口座に分ける（どの口座に いくら 入れるか。分けたら ✓）。口座をタップすると中身（何の支払いか）が開く |
| **＋** | 使ったお金を記録すると、変動費（食費など）の残りが出る |
| **推移** | 月ごとの固定費・変動費・積立と収入のグラフと表 |
| **設定** | 口座・名義の登録、貯金の口座、バックアップ、CSV |

### 口座に分ける額

その口座から払うものと、その口座に貯めるものの合計です。

- 手持ちは、現金で払うもの・封筒で取っておくものの合計を「現金でおろす」額として出します
- 給料が入る口座から払うもの（例：妻UFJの奨学金）は「残しておく」額として出します
- 口座に今残っているお金は考えに入れていません（毎月その額を入れる、という考え方です）

### カードの請求

カードで払うもの（電気代・水道代など）を入れたうえで、カードの「請求の合計」を入れると、
内訳を引いた残りが「その他の買い物」として変動費に入ります（二重に数えません）。
引き落とし口座に分ける額には、請求の合計が入ります。

### のこりが出たとき・足りないとき

- 足りない：［貯金から出す］→ 足りない分を貯金の口座から出したことにして、のこりを0にします
- あまる：［貯金に入れる］（貯金の口座に分ける額に足す）か［来月にまわす］（来月の「先月のあまり」に入る）
- 金額を変えると、出す・入れる額も自動で計算し直します

### 新しい月

アプリを開いたとき、今月の計画がなければ前の月をコピーして自動で作ります（✓ は外れた状態）。
項目をタップすると金額だけを変える画面が出ます（「先月と同じ」「0円」はワンタップ）。

## データの保存場所（大事）

記録は **使っている端末のブラウザの中だけ** に保存されます。どこにも送信されません。
そのため、ブラウザのデータを消したとき・機種変更したとき・別のブラウザで開いたときは消えます。
月に1回くらい「設定 → 全データをバックアップ（JSON）」で保存してください。新しい端末では「バックアップから復元」で戻せます。

## 使い始め方（GitHub Pages で公開する）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch** にし、このアプリのブランチと `/ (root)` を選んで **Save**
3. 数分後に表示される URL をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

※ 無料プランで GitHub Pages を使うには、リポジトリを Public にする必要があります。
公開されるのはアプリのプログラムだけで、家計のデータ（端末の中）は公開されません。
**家計のデータ（バックアップのJSONやCSV）はこのリポジトリに入れないでください。**

## CSV の形式

計画（設定 →「計画をCSVで書き出す」で出る形式。読み込みも同じ形式）

```
月,区分,項目,名義,口座,金額,済,メモ,請求の合計
2026-11,収入,給与,夫,夫SMBC1,250000,済,,
2026-11,固定費,電気代,,楽天カード,12000,,,
2026-11,変動費,楽天,,楽天カード,150000,,,○
2026-11,変動費,食費,,手持ち,30000,,,
```

- 区分は「収入」「固定費」「積立」「変動費」のどれか
- 口座が未登録の名前なら、読み込み時に銀行口座として登録します（種類はあとで変更）
- 「請求の合計」が ○ の行は、カードの請求の合計として扱います

使ったお金の記録

```
日付,項目,金額,メモ
2026-11-10,食費,3200,スーパー
```

文字コードは UTF-8（Excel の古い形式の Shift_JIS も読めます）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・処理すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで開けるようにするキャッシュ |
| `icons/` | アプリのアイコン |

`index.html` を更新したら、`sw.js` の `CACHE` の番号を上げてください（今は `kakeibo-v4`）。
